# LED POP 편집 화면 레이아웃 및 방향 정책

2026-09-11 후속 소스 변경 기록입니다.

## 디스플레이 영역

- 기존에는 편집 화면 미리보기 컨테이너 높이를 화면 가로 폭에 비례시켜 iPad와 넓은 태블릿에서 과도하게 커졌습니다.
- 폰·태블릿 및 iOS·Android 공통으로, 편집 화면 상단부터 프리셋 버튼 행 하단까지의 디스플레이 영역을 현재 화면 세로 높이의 31%로 계산합니다.
- 텍스트 입력 영역과 하단 Play 바·탭·설정 콘텐츠의 기존 높이와 동작은 유지합니다.
- `useWindowDimensions()` 값을 사용하므로 화면 크기 변화 후에도 세로 높이를 기준으로 다시 계산합니다.

## 화면 방향

- 메인 편집 화면은 iPhone, iPad, Android 폰 및 Android 태블릿에서 `PORTRAIT_UP`으로 잠급니다.
- 설정 화면 진입 시에도 `PORTRAIT_UP`을 명시적으로 재적용하며, 설정 하위 화면은 이 잠금을 해제하지 않습니다.
- Play 진입 시에만 기존 `unlockAsync()`를 실행하여 기기가 지원하는 가로·세로 방향을 모두 허용합니다.
- Play 종료 시 기존 동작대로 `PORTRAIT_UP`을 다시 적용합니다.
- iPad에서 런타임 방향 잠금이 작동하도록 `ios.requireFullScreen`을 활성화했습니다. 이에 따라 iPad Split View 등 멀티태스킹 창 모드는 지원하지 않습니다.
- Expo 정적 설정 확인에서 `UIRequiresFullScreen`은 `true`, 앱 기본 방향은 `default`로 확인했습니다. 새 iOS 네이티브 빌드와 실제 iPad/Android 태블릿 회전 검증은 아직 실행하지 않았습니다.

## iOS 키보드 완료 아이콘

- iOS의 Unicode 완료 글자를 Material Icons의 벡터 `check`로 교체해 글꼴별 색상 렌더링 차이를 제거했습니다.
- 아이콘은 도구막대의 대비 색상을 사용합니다. 어두운 iPhone 막대에서는 흰색, 밝은 iPad 막대에서는 기존 정상 표시와 같은 진회색입니다.
- 완료 동작, 크기, 터치 영역과 Undo/Redo 동작은 변경하지 않았습니다.

## 검증 범위

JSON 구문, Expo 정적 iOS 설정 및 Git 공백 오류를 확인했습니다. 컴파일·린트·테스트·새 빌드·실기기 검증은 실행하지 않았습니다. 기존 LED POP 1.0.8(26) APK/AAB는 이 후속 변경 전에 생성됐으므로 해당 파일에는 포함되지 않습니다.
