## 발견한 문제와 수정

`ads/rewardedState.ts`: 네이티브 표시 준비를 기다리는 동안 광고가 만료되거나 loaded 상태가 해제돼도 show가 호출될 수 있었습니다. await 이후 loaded/loadedAt/유효 기간을 재확인하도록 최소 수정했습니다. 재현 테스트는 수정 전 실패, 수정 후 통과했습니다. **수정은 소스에만 있으며 설치 APK에서 재검증하지 않았습니다.**

`node --test scripts/qa-ad-state.cjs`: 21개 통과. 실제 상태 모듈을 로드하고 SDK 경계·시계만 격리합니다. 배너 제한/재진입/refresh, 보상 중복/취소/만료/이벤트, SDK 초기화, 웹 이벤트 순서/비지원, production 콘솔 억제, 프리셋 복사/입력 보존을 다룹니다. 제품에 테스트 대역이나 보상 우회는 추가하지 않았습니다.
